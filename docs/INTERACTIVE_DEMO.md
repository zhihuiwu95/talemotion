最新：2026-09-09。已新增三个共用播放器的故事包，制作方式、第四篇任务与验证记录见 [生产验证](production/README.md)。以下保留原活动和第一版手套样片的试玩说明。

较早更新：2026-09-09。新增《雪地里的手套》故事样片，原四个活动保留作对照，详见 [MITTEN_STORY_SAMPLE.md](MITTEN_STORY_SAMPLE.md)。语音已统一升级为 Azure 晓晓多语言情绪音频，详见 [TTS_DECISION.md](TTS_DECISION.md)。

原版活动范围：方向 2：我们制作具体内容，孩子和家长玩故事。年龄和约 2–4 分钟时长是设计假设，尚未通过儿童试用验证，不能据此宣称认知提升。

## 四个活动

| 故事 | 观察点 | 内容 | 生活延伸 |
|---|---|---|---|
| 手套找朋友 | 理解“相同”、观察外观 | 给三位朋友配手套 | 给袜子配对 |
| 野餐准备好啦 | 大小比较、听指令 | 找大碗、小杯子、大垫子 | 指认大小不同的杯子 |
| 小球在哪里 | 里面、上面、下面 | 找盒子或凳子旁的小球 | 把玩具放进盒子 |
| 小花喝水啦 | 熟悉工具与生活先后 | 拿水壶 → 装水 → 浇花 | 大人陪同照顾植物 |

前三个面向约 2.5–4 岁；浇花标注为约 3–4 岁，小一点可由家长示范。每轮两个大按钮，没有识字要求、拖拽、倒计时、扣分、排名、自动续播。错误后描述相关特征，可以重试；成功后至少展示 1.8 秒并等待鼓励语音完成，再开放继续。跨按钮触控保护防止连击跳过反馈。静音或音频失败时仍可继续。再次游玩时交换左右选项，同一轮重试位置不变。孩子可指给家长看，不强求自己点。

## 运行与链接

```bash
npm install
npm run dev -- --host 0.0.0.0
```

手机连接同一 Wi-Fi，访问 Vite 输出的 Network URL。当前未公网部署；家长带回自己家试玩前，需要将 `npm run build` 的完整 `dist/` 部署到可访问的静态网站（包含 audio 目录）。

- `/`：故事选择入口、家长历史记录。
- `/?story=mittens`、`/?story=picnic`、`/?story=hide`、`/?story=garden`：各故事，可单独分享或刷新进入。
- `/?demo=classic`：旧两分钟动画引擎演示。

## 家长如何测试

1. 一次只选一个故事。先等孩子反应，不急着解释或指答案。
2. 不理解时，描述一次或示范一次。记录“自己做”“提示后做”“暂时没理解”，不要把提示后的完成当作独立理解。
3. 结束后观察是否主动想重玩；不想继续就休息。次日再试，比刚玩完连续重复更能观察持续兴趣。
4. 试一下生活里的活动，记录能否在换了物品后理解；需要额外提示也如实记录。
5. 请其他家长自己陪玩，然后填写是否愿意下次继续用，以及哪里不好理解。对产品价值的判断还需要真实复用行为，单次表态不是付费验证。

每个故事的“家长陪玩／记录这次试玩”提供三个选择题和选填备注，记录理解、重玩意愿、家长复用意愿。点击保存才写入 localStorage，最多 100 条；当前设备当前网址内保留，首页可查看、导出 JSON、确认清除。不采集姓名、录音，不上传，没有账号或自动埋点。当前轮进度仍只在内存；刷新或重玩重置当前进度，已保存的观察不受影响。导出文件可由家长自行分享给你。

内容设计参考：[Harvard 按年龄分组的亲子活动指南](https://developingchild.harvard.edu/resources/handouts-tools/activities-guide-enhancing-and-practicing-executive-function-skills/)。本项目不是该指南的验证产品，也不是儿童能力测评。

## 实现

- `src/play/StoryLibrary.tsx`：入口、URL 选择和返回导航；旧动画按需加载。
- `activities.ts` / `ActivityPlayer.tsx`：三个新故事的数据、阶段守卫、错误提示、完成、暂停和重玩。
- `story.ts` / `MatchingStory.tsx`：手套样片，保留原有配对与交还体验。
- `Artwork.tsx` / `ActivityArt.tsx`：原创本地 SVG，物品大小保持统一坐标比例，位置图展示相同小球与容器的关系。
- `Observation.tsx` / `observations.ts`：仅在家长明确保存时持久化观察。
- `EdgeAudioProvider`：预生成中文音频播放；制作命令见 [TTS 方案](TTS_DECISION.md)。无需手机安装 Edge，不调用手机 speechSynthesis。
- 后台或打开家长面板时停止旁白，暂停保留进度，恢复重读当前提示。支持静音、重听和声音失败后重试。
