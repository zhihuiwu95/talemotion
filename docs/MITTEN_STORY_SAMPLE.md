# 《雪地里的手套》短篇互动动画样片

更新：2026-09-09。按本轮确认，保留四个原版活动，只把手套主题新增为故事驱动样片。不批量扩关，也不建设复杂互动电影平台。

## 入口

- 新故事：`/?story=mittens-story`，首页「雪地里的手套」。
- 原版对照：`/?story=mittens`，首页「熟悉的小活动 → 手套找朋友」。
- 另外三个活动链接保持 `picnic`、`hide`、`garden`。

## 已实现的演出与互动

| 情节 | 孩子参与 | 画面后果 |
|---|---|---|
| 森林门口 | 点小熊，听它求助 | 小熊搓手、呼气，带出寻找原因 |
| 雪松旁 | 点积雪；也可先点雪松 | 积雪散开；可发现飞出的小鸟并获得线索 |
| 找到手套 | 点与小熊手上一样的手套 | 不合适时描述特征；相同的手套飞回，小熊戴好并庆祝 |
| 一起玩雪 | 选择堆雪人或踩脚印 | 两个选择都成立，进入不同画面与台词 |
| 小雪人 | 点小雪球 | 雪球成为雪人的头，小熊庆祝 |
| 小脚印 | 点前面的雪地 | 角色向前走，出现一串脚印 |
| 收尾 | 主动重玩、返回、记录 | 重玩清空选择、线索与尝试次数；没有自动开下一集 |

主体是连续舞台，不呈现题目编号、答案卡或下一题按钮。保留亲子暂停、静音、重听、后台暂停和主动观察记录。读屏按钮有场景动作名称，所有互动均支持点击和键盘操作，不要求拖拽。

## 实现边界

这是原创 SVG 角色、CSS 分镜动画、显式状态转换与录音同步组成的手套样片。沿用既有美术和 React，不为了一个短篇把旧 Scene Runtime 扩成通用分支编辑器；旧 Pixi/GSAP 引擎及经典入口继续保留。没有视频生成、真人视频、多声线角色配音、自由对话或在线生成剧情。

本片是一个小熊求助、一次配对、一个探索彩蛋和两种收尾。原版包含三位朋友三轮配对，两版内容量不同；此轮是玩法方向探索，不是严格控制变量的 A/B 实验，不用完成时长或答对次数比较学习效果。

## 亲子比较方式

在不同时间玩两版，尽量保持设备、音量与家长提示方式一致；也可以换一天调整先后顺序。观察：

1. 是否关注小熊戴上手套后的反应，而不仅是连续点按钮。
2. 是否理解自己的帮助，以及手套与后来能玩雪的关系。
3. 是否主动重玩、探索小鸟或另一个结尾。
4. 是否在听台词时持续观看，或明显着急等待。

记录功能只在主动保存时写入本机。两版名称分开记录；这些观察不代表认知测评。若孩子更喜欢密集操作，后续可缩短台词与演出空档，不预设故事版一定胜出。

## 本地验收

`npm run quality` 包含原活动回归、新样片两结尾与重试/重玩、跨屏连击、反馈时长、音频完成/失败、暂停时自动转换冻结、退出清理。浏览器另查 390 px、320 px 手机视口和桌面布局，以及真实 MP3 播放。

真实手机扬声器听感、触控与浏览器音频策略仍需家庭试玩；不把移动视口模拟写成手机验收完成。
