## 选题卡

- **主要目标**：在共同准备小聚会时，体验先听见两位朋友的具体愿望，再商量一项双方接受的摆放安排。
- **角色愿望**：小狐狸想让野餐篮靠近花，边吃点心边看花；小猫想给花留出空地，方便朋友走近小聚会。
- **孩子为何参与**：孩子先让两位角色说出想法，再帮助把篮子移到共同的起点；最后由孩子选择花边或开阔草地这个两人都同意的安排。选择改变最终画面的篮子位置、花的动态和角色回应。
- **来源**：TaleMotion 森林日常原创故事；不改编第三方角色、文字或插画。
- **教育依据与边界**：引用 `moe-social`、`naeyc-play`、`takacs-2015`，仅支持“在具体游戏中保留协商与自主选择、互动应服务叙事”的设计方向。它们不证明本游戏有效；不以完成、点击或分享衡量孩子的能力或品德。适用于 3–4 岁亲子共玩，语言理解需要时由成人支持。

## 梗概与自查

雨刚停，小狐狸和小猫想在花园办一场小聚会，却对篮子的位置有不同想法。孩子先听两人说清愿望；两位朋友同意先一起把篮子挪到草地中央。接着孩子选择让篮子靠近花，或放在更开阔的草地。两个结尾都保留花、篮子和两位朋友，只是位置、动态和回应不同。

自查：冲突来自同一件具体物品的位置，而非答题；共同移动篮子先建立双方接受的行动，再进入自由选择。两个选项不是“对/错”或品德考核；小猫的“给花留空地”和小狐狸的“靠花看看”都被角色明确接受。现有能力没有“坐下”“打开篮子”或真实花园布局，因此分镜不承诺这些不可见动作，只用已实现的位置、`deliver`、`wiggle` 与 `celebrate` 表达结果。

## Acceptance 路径

1. 花边小聚：`fox → cat → basket → flower`，自动经过 `basket-set`，到达 `flower-end`。
2. 开阔草地小聚：`fox → cat → basket → grass`，自动经过 `basket-set`，到达 `grass-end`。

## 能力缺口

无阻断缺口。故事只使用已列出的 `fox`、`cat`、`basket`、`flower`、`rain`、`meadow`、既有位置和动作。未表达的“坐下”“打开篮子”“真实花朵生长/采摘”不写入后果；如未来需要这些演出，应另开能力扩展。
