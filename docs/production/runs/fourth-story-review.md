| 必修：fox-wish、choose-place | “听小猫”的指令只在 cue/label 中；花与篮子分别代表两个地点，但 line 只说“一起选吧”。播放器只对 line 配音，不识字孩子无法从口头提示知道这层对应关系。 | fox-wish 加“点点小猫，听听它吧”；选择台词明确“点花留在这里，点篮子去左边草地”。文字标签同步这两个动作。 |
| 建议：choose-place → flower-end | 篮子仍在 prop-center，仅花 wiggle、朋友 celebrate；草地结尾则确实移到 prop-left。分支不是完全相同，也不是语法错误，但“位置选择”的一个结果主要靠口头解释。 | 明确花边选项是“留在这里”，另一选项是“移到左边”；后果描述与槽位一致。不要仅为了动起来虚构搬运动画。 |
| 建议：共同操作与两个结尾 | 实际只有篮子 deliver，角色仍站着；没有双人搬运。结尾缺少针对孩子贡献的感谢，更多是宣布地点。 | 以角色台词说明真实可表达的分工，收尾加具体感谢；不声称已经表现抬篮子、坐下或开篮动作。 |
