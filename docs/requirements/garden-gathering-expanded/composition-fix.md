# 雨后场景构图修正

本次按用户截图反馈进行局部视觉修复，适用 SDD design DES-11 / DES-12。保留柔和草绿、珊瑚花色、日光黄及现有字体。修正范围为 meadow-after-rain 背景和该背景内的角色、篮子样式；Story/Catalog 契约、三槽位置、分支、台词及音频不变。

原因：背景外层的 preserveAspectRatio="none" 同时拉伸太阳和花朵，宽屏上出现扁太阳、巨大花朵；篮子偏小，角色距前景道具过远，中央留白缺少聚会区域的视觉含义。

实现：仅地形层可伸缩，太阳与花簇使用独立等比 SVG；花簇置于场景右侧 62%～93% 区域并减小为三朵花，保留静态水滴和水洼；浅色草地连接三处摆放位置；角色向前靠近，篮子放大 30%。手机沿用 700px 分界。旧背景及其角色尺寸不变。

验证：完整 quality 结果见本次交付；原背景测试的旧坐标断言改为检查仅地形允许非等比缩放。没有使用 computer use、浏览器自动化或新增依赖。未进行视觉渲染验收：窄屏标签遮挡、四种布局的实际观感及亲子体验仍待人工预览。本轮未重绘角色的表情和肢体，先解决比例、拉伸与构图问题。
