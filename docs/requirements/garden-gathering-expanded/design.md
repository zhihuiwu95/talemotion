# 雨后的花园小聚会：互动分镜与演出设计

## 1. 状态与设计方向

- REQ-GARDEN-EXPANDED；Design v0.2，2026-09-13；用户已授权落实 review 并进入架构。具体扩展决策以待确认的 arch.md 为准。
- 依据 [PRD v0.3](prd.md)、[设计基线 v1.0](../../sdd/design.md)、[能力目录](../../production/CAPABILITIES.md)。当前代码基线 `0662184`，本轮开始工作区干净；与 PRD 初次基线的差异只记录，不回写历史。
- 用户已授权 PRD review 修订并进入 Design；本文件不是架构或实施授权。未修改故事、素材、播放器、声音或契约。
- 核心体验：孩子帮朋友试摆，发现中间要留给鼓，选择把篮子挪到哪边；腾出的中间真正用来演奏；活动之后看看花和篮子，让故事安静落下。
- 适用 DES-01～09、11～18；无新字体、配色或产品页面。两项能力扩展见第 8 节，须用户确认后才进入架构。

## 2. 舞台与角色

角色固定：小狐狸左、小猫右；开场 neutral，位置安排被接受后 happy。保留两位角色至尾声。小狐狸爱看花，小猫期待和朋友玩鼓；不把角色写成对错两方。

建议新增可复用的“雨后花园”背景，暂名 `meadow-after-rain`。花作为场景固定部分，不占可点击道具位。背景从开始到结束不变；旁白说明雨停了，不绘制持续降雨。

花丛向中间延伸，主体候选区域 x=65%～80%、y=52%～70%；须结合篮子实际图形边界调整，让中槽篮子肉眼可见地靠花、右槽篮子更靠花。篮子仍占标准中槽，不引入“中间偏右”槽位。沿用既有花朵 SVG 造型与配色，避免遮住右侧角色面部。此为待实装验证的布局目标，不是当前能力或测量结果。天空放晴，增加少量静态叶片水珠与浅水洼；水洼避开三个摆放位，装饰不可点击。不增加雨珠动画或第二套花景背景。

| 布局 | 左侧道具位 | 中间道具位 | 右侧道具位 | 故事含义 |
|---|---|---|---|---|
| L0 开场 | 篮子 | 空 | 小鼓 | 道具先放在两位朋友面前 |
| L1 试摆 | 空 | 篮子 | 小鼓 | 篮子来到花丛延伸处；中间被占用，必须由实际构图成立 |
| LF 花边安排 | 空 | 小鼓 | 篮子 | 篮子更靠右侧花，小鼓用腾出的中间 |
| LG 草地安排 | 篮子 | 小鼓 | 空 | 篮子在左边，仍能看见右侧花 |

“冲突”具体是小猫希望把鼓摆在中间，让两位朋友都方便加入，不声称整个花园没有地方。它第一次提出这个需要是在试摆之后。避免先展示充足空地，却泛泛说“哪儿都放不下”。

花边分支中篮子与鼓交换占位，使用下一幕最终快照明确结果；不把 `deliver` 的右上方入场伪称为精确横向搬运。小猫口头承担挪鼓，孩子负责篮子。两个物体的新位置同时呈现。

道具沿用现有尺寸：窄屏左/右宽 28%、中间宽 30%，底部 7%、高 29%；桌面沿用既有槽位。儿童目标至少 60×60 CSS px、家长按钮至少 44×44，最窄检查 320px。设计未实测；若不达标须调整，不把百分比当热区证明。

## 3. 完整分镜：共同开场（8 个节点）

表内引号为候选正式口头台词，每节点单一 speaker，均不超过 64 字符。B 自动演出；I 等待点击；E 结束。B 的 cue 只描述观看，不指示点击。除列出的目标外，其余实体不可选。开场“走进故事”仍由既有欢迎页提供。

| ID / 类型 | 画面与动作 | 配音台词 | 操作、后果与去向 |
|---|---|---|---|
| s01 / B | L0，双方静止 | 朵朵：“雨停了，小狐狸和小猫带着篮子和小鼓，来到花园。” | 自动到 s02 |
| s02 / B | L0，狐狸 wiggle | 小狐狸：“我带了野餐篮，想找个能看见花的地方，和大家一起聚会。” | 自动到 s03 |
| s03 / B | L0，小猫 wiggle | 小猫：“我带了小鼓，等下我们一起玩音乐吧！” | 自动到 s04 |
| s04 / I | L0，仅篮子可点 | 小狐狸：“我们先放花这边试试吧。点点篮子，帮我挪到中间。” | `try-basket`：篮子左→中，到 s05；共同试摆，不设错误 |
| s05 / B | L1，篮子静止，鼓仍在右 | 小猫：“篮子摆好啦！我想把小鼓放在中间，让大家都能一起玩。咦，中间有篮子呢。” | 自动到 s06；位置占用可见 |
| s06 / B | L1，狐狸 wiggle | 小狐狸：“那我们挪一挪吧。我还是想让篮子靠花一点。” | 自动到 s07 |
| s07 / B | L1，小猫 wiggle | 小猫：“中间留给小鼓就好。篮子放花边或左边，我都喜欢。我来挪鼓！” | 自动到 s08 |
| s08 / I | L1，两位角色可点；物品保持 | 小狐狸：“左边也能看花，我也喜欢。点我，篮子去右边花旁；点小猫，篮子去左边草地。” | `flower`→f01；`grass`→g01；两项均 free |

选择布局时不增加花/空地图示，不挤占道具位。角色在此是已经口头解释过的两个选择目标；字幕标签分别为“篮子去右边花旁”“篮子去左边草地”。角色目标不代表角色偏好投票，两位角色已分别同意两处。

## 4. 完整分镜：布局结果、音乐和尾声（每种布局 13 个节点）

下表 X 代表 f 或 g；表内 LF/LG 按所选路线固定。共用文字分别落在各自画面节点中，不能在播放时丢失篮子位置。只有 x01 文本按布局不同，其余台词相同。

| ID / 类型 | 画面与动作 | 配音台词 | 操作、后果与去向 |
|---|---|---|---|
| x01 / B | LF 或 LG；篮子与鼓呈现最终位置，狐狸 happy | 花边，小狐狸：“篮子靠着花，小鼓到了中间，真合适！”；草地，小狐狸：“篮子在左边，也能看见花，小鼓到了中间，真合适！” | 自动到 x02；小猫负责把鼓由右挪到中间 |
| x02 / B | 所选布局持续，小猫 happy | 小猫：“这里敲鼓，大家都能加入啦！谢谢你帮忙挪篮子。” | 自动到 x03；双方认可兑现 |
| x03 / I | 同布局，小猫与鼓可点 | 小猫：“小聚会开场啦！想一起拍手，就点点我；想敲小鼓，就点小鼓。你来选！” | `clap`→x04c；`drum`→x04d；free，不判错 |
| x04c / B | 同布局，小猫与鼓 play | 小猫：“咚咚，哒！听，我先敲起来啦！” | 自动到 x05c |
| x05c / I | 同布局，小狐狸唯一目标；其余 still | 小狐狸：“我也想加入！点点我，我们一起拍拍手吧！” | `join-clap`→x06c；target=fox |
| x06c / B | 同布局，小狐狸、小猫与鼓 play | 小狐狸：“拍拍，咚咚！我跟上鼓声啦！” | 自动到 x06；点狐狸后狐狸加入，小猫继续演奏；不承诺手指动画 |
| x04d / B | 同布局，小猫与鼓 play | 小猫：“咚咚，哒！这一小段敲完啦，接下来请你和小狐狸一起！” | 自动到 x05d；自然一小段，无等待考核 |
| x05d / I | 同布局，鼓唯一目标 | 小狐狸：“小鼓就在中间呢。点点小鼓，和我一起敲吧！” | `join-drum`→x06d |
| x06d / B | 同布局，狐狸与鼓 play | 小狐狸：“咚咚，咚咚！我们的鼓声也响起来啦！” | 自动到 x06；这里的鼓声为角色口中节奏，见声音边界 |
| x06 / B | 同布局，双方 happy、静止，结束节奏动作 | 小猫：“刚才还要找地方，现在我们都能围着小鼓玩啦。” | 自动到 x07；成果回应，无新操作 |
| x07 / B | 同布局，花、篮子、小鼓均保留；无跳动 | 小狐狸：“花还看得见，咚咚歌也真好听。和你们一起，我真喜欢。” | 自动到 x08；独立尾声，回扣开场看花愿望 |
| x08 / B | 同布局，安静保留结果 | 朵朵：“花园里的小聚会，留下了一段咚咚歌。小狐狸、小猫，下次再一起玩吧。” | 自动到 x09；告别，不设置下一集悬念 |
| x09 / E | 同布局，双方 happy、still | 小猫：“下次见！” | 既有回到首页、重玩、成人记录；不自动下一篇 |

尾声 x07 不使用 celebrate，不增加点击或固定长等待；沿用台词播放完成与最短演出双条件。x08 告别结束后才进入 E。x09 的短回应可与结束按钮同屏，但故事的尾声与主要告别已经完成。

情绪路径：期待 → 好奇地发现 → 共同调整 → 音乐的热闹 → 成果满足 → 安静回看 → 告别。内容审阅要读出这一变化，不能仅因有 x07 就认定自然收尾成立。

| 花边＋敲鼓 | try-basket → flower → drum → join-drum | f01→f02→f03→f04d→f05d→f06d→f06→f07→f08→f09 | LF 到结束；敲鼓反馈后汇合 f06 |

| 草地＋敲鼓 | try-basket → grass → drum → join-drum | g01→g02→g03→g04d→g05d→g06d→g06→g07→g08→g09 | LG 到结束；敲鼓反馈后汇合 g06 |

每条路径先经过 s01～s08。全图 34 节点；单次拍手与敲鼓路径均为 18 节点；两者均 4 次有效点击。数量是此设计的结果，不是适龄标准。比旧版增加的是情节和结果体验，未靠连续点角色听下一句增加操作数。

两种位置路线不合并画面；音乐路线在各自布局内汇合。位置选择保留到最终结束；若未来要统一场景，必须有新的、已演出的搬动理由，本设计没有该动作。

## 6. 声音、交互和页面状态

声音提案：使用现有预生成角色语音表达“咚咚、哒、拍拍”，配合 play 动效。不加入节拍识别或真实拍手采集；独立短音效作为架构重点决策，尚未试听，不能预断语音节奏已足够。此版本是点击触发角色回应的互动绘本，不能宣传为可自由演奏的小鼓。

音乐有辨认风险：口头节奏和仅 1.7 秒摆动未必产生足够参与感。在全面实现与正式配音前设置小段试听决策，比较 x04c/x06c/x04d/x06d 的表达；若语音节奏不足，优先考虑最小通用短音效，不通过延长台词或增加点击补救，不能把语音生成成功写成音乐体验通过，也不擅自改变已确认范围。

新增台词沿用当前语音管线和已审定角色配置；本设计不批准全项目声线切换。逐句读音审阅在内容实现阶段落实，重点复核“小鼓、空地（若后续使用）、一起、地方、敲一小段”等最终文本语境；本文件不宣称已完成发音审定。

| 状态 / 页面 | 表现与操作 | 关联 AC |
|---|---|---|
| P-01 小屋 / P-02 未开始 | 独立新故事卡，既有开始按钮；标题与副标题不出现实验评分 | 08 |
| P-02～05 自动演出 | 台词与场景同步开始；故事选择锁定，cue 为“看一看，听一听”；成人可暂停/退出 | 01、05、07、09 |
| P-03/04 等待选择 | 可点目标具标签、焦点与既有按下反馈；语音结束后解锁；不依赖 hover | 02～04、06 |
| 暂停 / 恢复 | 动画和语音暂停/取消，恢复重播当前节点，沿用现有保护 | 07 |
| 静音 / 音频失败 | 字幕与完整布局可读，成人可代读节奏；最短演出/故障释放沿用，不永久卡住 | 07 |
| 减弱动态 | 关闭摆动仍保留所有结果布局；用台词与字幕表达参与方式 | 03、04、10 |

故事无答错路径，不新增错误提示五态。故障处理、连击、防穿透、焦点、退出按钮和字幕区域复用既有设计；不复制播放器。画面与字幕分区，窄屏允许合理滚动，检查标签不压住邻近目标。

## 7. 梗概到演出的取舍

- 小狐狸期待找个能看花的地方聚会，不再承诺吃点心；篮子是布置聚会的物品。两种布局均保留看花条件。同步 PRD AC-01。
- 不演出坐下、角色手指拍合、挥手或雨珠落花；告别通过对白和安静的共同画面表达。若用户希望把这些动作作为体验核心，需另列能力需求。
- 首次提示“先放花这边”，花丛实际向中槽延伸；右槽更靠花。检查四种布局图形边界和相邻关系，不能靠坐标范围或文字说明认定视觉成立。
- 小鼓先在小猫面前的右侧，后来希望放中间供大家加入。发现的是共同活动的位置需要，不是强行制造物理上无处放鼓的问题。

## 8. 能力扩展与架构决策入口

| 提案 | 必要性与范围 | 替代及代价 | 验证要求 |
|---|---|---|---|
| 新增通用 meadow-after-rain 背景 | 固定花景释放道具位，让篮子两种位置与中间小鼓全程真实保留；沿用现有 SVG 花形，无新外部图片 | 继续用花道具会占右位，花边分支无法同时容纳中间鼓与靠花篮子；把花藏掉会削弱尾声回扣 | 新背景注册、静态画面、320px 花/角色/道具不遮挡；既有背景不变 |
| 将故事最大节点数由 24 调整为 40 | 本设计 34 节点，分支布局使用独立完整快照；单次只走 18 个节点，不引入条件变量或新状态机 | 压成 24 会要求改写当前分镜、减少角色表达/尾声，或引入更复杂的状态继承 | 架构阶段明确兼容、目录/文档导出、40/41 边界与既有路径回归；不能只放宽校验器 |

40 是本次拟定的有限上限，不是性能测量结论；schema/catalog 版本与迁移策略在下一步架构阶段明确。普通故事作者仍不能自行突破上限。现阶段只列提案，不修改共享基线或契约。

## 10. 架构核对补充

当前 schema 要求 start 为 interactive，但本设计 s01 为 beat。架构必须显式支持新版本故事在点击既有“走进故事”后自动演出开场；不能为通过校验额外塞一个点角色听下一句。现有 v1.0 起点规则保留。

候选片段试听为下一阶段首个受控步骤，不在本次文档工作中生成声音。若用户选择加入短音效，音乐节点的精确对白/音效次序需随试听结果记录；单次路径和四次点击不因此改变。
