## 2. 问题、用户与目标

现有《雨后的花园小聚会》一次路径为 6 个节点、4 次点击，选好位置就结束，尚未展开真正的聚会。用户反馈故事太短、突然结束、不成体系。本次先制作一个完整样篇，检验故事展开与收尾；系列建设留待样篇反馈后讨论。

面向 3–4 岁儿童与陪玩成人。儿童通过点选参与，成人可解释字幕、回应和协助操作；不以完成速度或正确话术判断能力。

主要目标：孩子在准备聚会时，体验发现空间问题、听见双方愿望、共同调整，并参与调整后真正发生的聚会。

体验目标：从“选好地方即结束”变为“尝试—发现问题—调整—享受成果—尾声回扣—告别”。不以增加字数、等待时间或机械点击作为达标依据。实际时长在可播放版本中测量，当前未知，不预设经验证的适龄分钟数。

## 3. 已确认的故事主线

1. **期待**：雨停后，小狐狸带来野餐篮，想边吃点心边看花；小猫带来小鼓，期待演奏。邀请孩子布置聚会。
2. **尝试**：小狐狸提出先在花旁试摆，孩子帮助完成；随后共同发现篮子占用了小猫希望摆鼓的位置。首次尝试合理，不归咎于儿童，不标记答错。
3. **理解**：小狐狸想靠近花，小猫想留出摆鼓和一起玩的地方；双方愿望通过各自台词表达。
4. **调整**：孩子选择篮子靠花但让出中间，或把篮子放到左边草地。两种安排都保留看花与玩鼓的条件，双方分别回应。
5. **兑现**：位置安排好以后，聚会实际开始。小鼓进入刚刚腾出的位置，篮子保留调整后的布局。孩子选择拍手加入或听完一小段后敲鼓，每条分支都有参与过程和结果反馈；音乐只兑现共同准备的成果，不承担第二个教学目标。
6. **尾声与告别**：音乐活动完成后，两位朋友享受成果；独立尾声回扣看花与玩音乐的开场愿望，不增加任务。然后告别，再进入结束操作区。

以上是情节承诺，不是逐字台词或已经实现的动作。分镜阶段须逐项给出实际画面与声音证据。

## 5. 用户故事与验收

| US | 用户希望 |

| US-01 | 儿童能理解朋友期待怎样的聚会，以及为什么需要帮忙 |
| US-02 | 儿童能尝试与选择，并看到选择改变了什么 |
| US-03 | 儿童能参与准备好的聚会，经历完整结尾 |
| US-04 | 成人能按家庭节奏陪玩、停止，并比较新旧版本 |

| AC | US | Given / When / Then | 验证层级 |
|---|---|---|---|
| AC-01 | US-01 | 给定故事开始，首次摆放前通过角色台词建立看花吃点心与一起玩音乐的期待；首次尝试出现空间冲突后，再表达具体位置需要。儿童理解程度由家庭观察另行判断 | 分镜/台词审阅 |
| AC-02 | US-02 | 给定首次摆篮子，当准备摆鼓，画面和台词共同表达位置占用；首次摆放由角色提出，是合理共同尝试，调整源于新发现，不责备儿童或标记答错；不能只有作者备注声称拥挤 | 分镜/状态核对；视觉待预览 |
| AC-03 | US-02 | 给定双方表达愿望，当选择任一种安排，篮子与鼓的位置或状态真实改变，且双方各自认可；两种安排均不判错 | 内容/路径测试/视觉 |
| AC-04 | US-03 | 给定位置安排完成，当进入任一种音乐分支，孩子至少有一次真正参与音乐活动的操作，随后有独立结果反馈；不能选择玩法后直接进入 ending | 内容/路径测试/真实播放 |
| AC-05 | US-03 | 给定活动完成，当故事收尾，先有成果回应、独立尾声与告别，再进入 ending；结束区不在尝试、调整或音乐活动中出现 | 内容/路径测试 |
| AC-06 | US-02 | 给定等待必要操作，当台词结束，孩子已获得口头操作说明或明确建立的视觉线索；不依赖阅读 cue/label 才能推进 | 逐句审阅/家庭观察 |
| AC-07 | US-04 | 给定新故事任一路径，当暂停、恢复、静音、声音失败、快速点击或退出，沿用公共保护与降级；重玩从开头开始，退出清理声音 | 既有相关测试/本地验证；手机声音单列 |
| AC-08 | US-04 | 给定新版本加入，当打开新旧故事入口，两者独立可访问，旧故事与历史记录保持可对照；新包全部节点与选择均有验收路径，且明确覆盖花边/草地 × 拍手/敲鼓四种组合 | 文件差异/结构与路径测试 |
| AC-09 | US-03 | 给定聚会及结果反馈已完成，当进入告别前，有独立尾声回扣本篇环境、物品、关系或开场愿望，呈现享受成果的状态；不引入新问题或必要操作，不以泛泛感谢代替尾声 | 分镜/真实播放/用户体验反馈 |
| AC-10 | US-02/03 | 给定已选择布局，当进入音乐及尾声，篮子保持所选位置，小鼓实际使用腾出的位置；音乐不是无关场景或新的协商教学任务 | 四组合状态核对/路径测试/视觉 |

家庭观察重点：孩子是否关注双方愿望、能否感知调整的后果、是否有参与聚会的机会；由成人记录具体表现和支持程度。不设能力达标分数。用户主观判断“是否仍突然结束”单独记录，不由工程通过替代。

## 6. 页面、状态与规则

主路径：P-01 故事小屋 → P-02 开场 → P-03 筹备/选择/反馈 → P-04 聚会参与 → P-05 成果回应、尾声与告别 → P-06 结尾。

沿用开始、演出锁定、等待选择、暂停、恢复、重听、静音/声音失败、返回首页与主动重玩的既有行为。P-05 使用正常剧情承载收尾；P-06 沿用当前“回到首页”等结束操作。全程允许成人退出，不强制记录或继续。

自由选项都成立；分支可汇合，但要先给不同的可见结果或明确角色回应。音乐分支均应完整，不能让其中一路只有一句“真开心”就结束。物品、位置与天气应前后连续。四条组合都须标出分支、差异反馈与汇合点；共用台词不等于必须共用画面节点，不得因汇合丢失位置选择。
